# Three-Page Portfolio Starter

A semantic HTML starter for a personal portfolio with Home, Projects / Work, and About / Contact pages.

## Files
- `index.html` — Home page
- `projects.html` — Projects / Work page
- `about.html` — About / Contact page
- `wireframe.png` — updated low-fidelity layout plan for all three pages

## Design direction: Welding / Metal Fabrication
- **Neon red:** `#FF1744` — high-energy highlight
- **Neon orange:** `#FF6D00` — welding sparks and call-to-action accent
- **Neon yellow:** `#FFE600` — high-visibility safety accent
- **Steel gray:** `#8A949B` — metallic neutral
- **Dark steel:** `#252A2E` — industrial background and strong contrast
- **Light steel:** `#E5E9EC` — clean content background
- **Fonts (planned):** a bold, condensed sans-serif such as Oswald for headings, paired with a readable sans-serif such as Inter for body text.
- CSS is intentionally not included yet; this submission focuses on HTML structure and meaning. The palette and fonts are design specifications for a later styling stage.

## Navigation
Each page has the same semantic `<nav>` with relative links to all three HTML files.
